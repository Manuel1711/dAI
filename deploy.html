Deploy Control Panel

Operational entrypoint for protocol actions (register agent, give/respond feedback) and deployment status.

API status

Mode: external runtime required (not served by GitHub Pages).

Health endpoint: /health

Security: Bearer token + rate limit + audit log.

Available actions

  • POST /agents/register
  • POST /feedback/give
  • POST /feedback/respond

Deployment checklist

  • Set OPS_API_TOKEN
  • Configure RPC endpoint
  • Enable dryRun=false only after validation
  • Verify health + audit logging
